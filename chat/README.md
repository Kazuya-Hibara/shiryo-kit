# shiryo-kit チャット版 — ChatGPT・Claude・Gemini に貼って使う資料づくりの手順

セミナー資料・顧問先への説明資料・提案資料・報告資料の「中身」を、AI と一緒に作るための指示文です。
ふだん使っている ChatGPT・Claude・Gemini に、文章を 1 つ貼る (または 1 つのフォルダを入れる) だけで使えます。ソフトの導入は要りません。

> **この版は、まだ実際のアプリで最後まで試していません (未検証)。**
> AI に会話の代役をさせて動きを確かめた段階です。下の表の「未検証」は、実際の ChatGPT・Claude・Gemini で試し終えたら外します。

---

## 1. この版でできること

AI が次の順番で進めます。

1. **聴き取り** — 作り始める前に、目的・聴く人 (読む人)・欲しい物 (スライド、読み原稿など)・時間や場面・何日時点の制度で書くか・入れない話題・口調などを聞きます。おすすめの答えが付いているので、「はい」か番号で答えられます。
2. **要約の確認** — 聞いた内容をまとめて見せます。あなたが「この内容で」と答えるまで、資料は作りません。
3. **骨子** — スライドのタイトルだけの一覧。タイトルは「結論を 1 文で言う」形です。
4. **スライド文面** — 1 枚ごとのタイトル・本文・図や表の中身。
5. **読み原稿** — 1 枚ごとに、声に出して話す言葉で。目安の時間つき。
6. **出典一覧** — 法令・制度・金額・日付・対象などの主張ごとに、どの公的な資料で確かめたか (引用つき)。確かめられなかった所は資料の中に **[要確認]** と出し、数字を作りません。
7. **確認リスト** — 使う前にあなたが確かめること。
8. **メモカード** — 次回のためのメモ。次に資料を作る時、新しい会話の最初に貼ると、同じことを一から聞かれずに済みます (`memo-card.md`)。

## 2. ご注意 — チャット版はエージェント版より品質が少し落ちます

> **チャット版は、エージェント版 (Claude Code・Codex で動く版) より品質が少し落ちます。** 理由は次の通りです。大事な資料・外に出す資料ほど、出典一覧の URL を必ずご自分で開いて確かめてください。
>
> | エージェント版にあって、チャット版で弱くなる所 | なぜ弱くなるか | チャット版での代わり |
> |---|---|---|
> | 過去の資料を AI が自分で探して読み、口調を抜き出す | チャットアプリは、あなたのパソコンのフォルダを読めません | 過去の資料を手で添付するか、文章を貼る。添付が少ないと口調の反映が浅くなります |
> | 公的な原典のページを取得して保存し、引用が本文に本当にあるかをプログラムで確かめる | チャットアプリの検索機能に任せるしかなく、AI が本当にそのページを開いたかを機械で確かめられません。検索機能が使えない設定だと、ほとんどが [要確認] になります | 出典一覧に引用と URL を出すので、あなたが開いて確かめる |
> | 作った AI とは別の AI が、原典を開き直して点検する (検品) | 同じ会話の中では、作った AI が自分で見直すことしかできません | 「検品済み」とは名乗らず「未検品」と表示し、確認リストを渡します |
> | 数字と出典一覧の食い違い・言ってはいけない表現・文字の欠けを、プログラムで確かめる | チャットアプリではそのプログラムを動かしません | 確認リストで、あなたが目で確かめる |
> | 聞いた内容をフォルダに保存して次回使う | 会話が終わると、前回の答えを覚えていません | メモカードを貼り戻す |
> | 編集できる PowerPoint (.pptx) を作り、崩れを確かめる | 描画は各社のスライド機能に任せます。文字が編集できるか・日本語が崩れないかは各社次第で、確かめていません | 描画の後で、文言・数字が変わっていないかを確かめる (§6) |
>
> もう 1 つ。**チャットアプリに貼った内容は、各社のサーバーに保存されます。** 顧問先の従業員や相談者の名前・連絡先・健康のことなどは貼らないでください (指示文でも「写さない」としていますが、貼らないのがいちばん確かです)。会話の内容がどう扱われるか (学習に使われるかなど) は、各社の設定と契約で違います。各社の案内でご確認ください。

## 3. 対応環境の一覧

**全部「未検証」です** (実際のアプリで入口から成果物まで通す試験 U-01 がまだ)。契約や設定は 2026-10-18 時点で各社の公式ページを調べた内容です。「(要約で確認)」は、公式ページの本文が開けず、検索結果の要約でしか確かめられなかったものです。

| 対応環境 | 状態 | 必要な契約 | 初期設定 | 使えない機能・注意 |
|---|---|---|---|---|
| ChatGPT の「プロジェクト」 | 未検証 | 無料を含む全プランで使える (要約で確認) | プロジェクトの指示に `instructions.md` を貼る。参考資料 3 つを入れてもよい (無料プランはファイル 5 つまで (要約で確認)) | カスタム GPT は使いません。個人のアカウントでは新しく作れず、2026-12-11 に終了予定のため (要約で確認)。個人設定の「カスタム指示」欄は文字数が足りないので貼らない |
| Claude の「プロジェクト」 | 未検証 | 無料を含む全プラン。無料はプロジェクト 5 つまで | プロジェクトの指示に `instructions.md` を貼る。参考資料 3 つをプロジェクトのファイルに入れてもよい | Web 検索は全プランで使える (無料は利用量に上限)。検索が使えない設定だと出典は [要確認] になる |
| Claude のスキル | 未検証 | 無料・Pro・Max・Team・Enterprise | 「コード実行とファイル作成」を ON にして、`shiryo-kit-chat` フォルダを zip にしてアップロード (§4-3)。Team・Enterprise は管理者が Skills を ON にする必要あり | スキルの中で道具 (プログラム) は動かしません。Claude Slides と組み合わせられる (§6) |
| Gemini の「Gem」 | 未検証 | 公式ページに契約の記載なし。13 歳以上・ログインが必要 | Gem の指示に `instructions.md` を貼る。「知識」に参考資料 3 つを入れてもよい。Gem は Web 版 (パソコンのブラウザ) でだけ作れる | **個人の Google アカウントでは、2026-11-17 から Gem がなくなり、自動で「スキル」に移ります** (仕事用の Google Workspace は 2027-03-01 以降)。Gem で Google 検索が使えるかは公式ページに記載なし |
| Gemini の「スキル」 | 未検証 (試していない) | Google AI の契約は不要。18 歳以上・「アクティビティを保持」が ON | `shiryo-kit-chat` フォルダか、その zip をアップロード (Claude 用と同じフォルダ) | Gem の後継。このフォルダで動くかは確かめていない |

共通して使えない機能: §2 の表の左の列 (過去資料の自動読み取り、原典の取得と機械照合、別の AI による検品、機械チェック、編集できる pptx の書き出し、聞いた内容の自動保存)。

## 4. はじめての準備 (アプリごと)

どのアプリでも、使うのは次のファイルです。

| ファイル | 中身 | 使い方 |
|---|---|---|
| `instructions.md` | 指示文 (約 5,200 字) | 全文をコピーして、指示の欄に貼る |
| `knowledge/hearing-guide.md` | 聴き取りの手引き | 入れなくても動く。入れると聞き方が安定しやすい |
| `knowledge/evidence-rules.md` | 出典の確かめ方 (どの役所のどのページを見るか、施行日の確かめ方) | 同上。法令・制度の資料なら入れるのがおすすめ |
| `knowledge/doctrine.md` | 資料の判断の軸 (タイトルの付け方、話す資料と配る資料の違い、4 つの型) | 同上 |
| `claude-ai-skill/shiryo-kit-chat/` | Claude (と Gemini) のスキル用フォルダ | §4-3 |

指示文を貼る時は、`instructions.md` をメモ帳などで開き、**全部選んでコピー** (Windows は Ctrl + A → Ctrl + C、Mac は ⌘ + A → ⌘ + C) して貼ります。途中で切れないように、最後の行 (「…この指示文を優先する。」) まで入っているか確かめてください。

### 4-1. ChatGPT (プロジェクト)

1. ChatGPT の左の欄で「プロジェクト」→ 新しいプロジェクトを作る (名前の例:「資料づくり」)。
2. プロジェクトの右上の「…」→「プロジェクト設定」を開き、指示の欄に `instructions.md` の全文を貼って保存。
3. (任意) プロジェクトのファイルに `knowledge/` の 3 つのファイルを追加。
4. そのプロジェクトの中で新しいチャットを始め、「セミナー資料をお願いします」のように頼む。

### 4-2. Claude (プロジェクト)

1. claude.ai の「プロジェクト」→ 新しいプロジェクトを作る。
2. 「プロジェクトの指示を設定」(Set project instructions) に `instructions.md` の全文を貼って保存。
3. (任意) プロジェクトのファイルに `knowledge/` の 3 つのファイルを追加。
4. そのプロジェクトの中で新しいチャットを始めて頼む。

### 4-3. Claude (スキルとして入れる) — プロジェクトの代わりに

スキルにすると、どのチャットからでも「資料作って」と頼むだけで使えます。

1. claude.ai の「設定」→「機能」(Capabilities) で「コード実行とファイル作成」(Code execution and file creation) を ON にする。
2. `claude-ai-skill` の中の **`shiryo-kit-chat` フォルダごと** zip にする。
   - Mac: Finder で `shiryo-kit-chat` フォルダを右クリック →「"shiryo-kit-chat" を圧縮」→ `shiryo-kit-chat.zip` ができる。
   - Windows: エクスプローラーで `shiryo-kit-chat` フォルダを右クリック →「送る」→「圧縮 (zip 形式) フォルダー」(Windows 11 は「ZIP ファイルに圧縮する」)。
   - **フォルダの中身だけを選んで zip にしないでください。** zip を開いた時に、まず `shiryo-kit-chat` フォルダが見える形が正解です (中に `SKILL.md` と `references` フォルダ)。
3. claude.ai の「カスタマイズ」→「スキル」→「+」→「スキルを作成」→「スキルをアップロード」(英語の画面では Customize → Skills → + → Create skill → Upload a skill) で zip を選ぶ。
4. 新しいチャットで「セミナー資料を作って」と頼む。

### 4-4. Gemini (Gem)

1. パソコンのブラウザで Gemini を開き、左の欄の「Gem」→ 新しい Gem を作る (名前の例:「資料づくり」)。
2. 「指示」の欄に `instructions.md` の全文を貼る。
3. (任意) 「知識」の「ファイルを追加」で `knowledge/` の 3 つのファイルを追加。
4. 保存して、その Gem でチャットを始める。

個人の Google アカウントでは 2026-11-17 から Gem が「スキル」に自動で移ります。移った後もそのまま使えるかは、まだ確かめていません。新しく始める場合は、Claude 用と同じ `shiryo-kit-chat` フォルダを Gemini の「スキル」にアップロードする方法もあります (未検証)。

## 5. 使い方 (毎回)

1. 新しいチャットで頼む。前回のメモカードがあれば、最初に貼る。過去の資料 (pptx・pdf・文章) があれば添付する。
2. 聞かれたことに答える。おすすめの答えのままでよければ「はい」、違う所だけ「2: 45分」のように番号で。
3. 要約が出たら、内容を確かめて「この内容で進めてください」。直す所があれば言う (直した要約がもう一度出ます)。
4. 骨子 → スライド文面 → 読み原稿 → 出典一覧 → 確認リスト → メモカード の順に出てきます。長い時は途中で止まるので「続けて」と送る。
5. 確認リストに沿って確かめる。特に **[要確認] の所と、出典一覧の URL** は必ず自分で開く。
6. メモカードを保存しておく (メモ帳などに貼って保存)。

うまく進まない時:
- 質問が多すぎる → 「急いでいるので、おすすめの答えで要約を出して」と頼む (それでも要約への「はい」は聞かれます)。
- 出典が全部 [要確認] になる → アプリの Web 検索が OFF になっていないか確かめる。公的なページの本文を自分でコピーして貼れば、それを出典として使います。
- AI が「確認済み」と言うのに引用が無い → 「引用を見せてください」と頼む。引用が出なければ、その行は未確認として扱ってください。

## 6. スライドの見た目にする

チャット版が作るのは文章 (スライド文面・読み原稿・出典一覧) です。見た目のスライドにするには、次のどれかを使います。**どれを使っても、描画の後で文言・数字・[要確認] が変わっていないかを確かめてください** (描画の時に AI が言い換えたり、[要確認] を消したりすることがあります)。

| 道具 | 必要な契約 (2026-10-18 時点) | 書き出せる形式 | 注意 |
|---|---|---|---|
| **Claude Slides** (claude.ai のスライド機能) | 無料を含む全プラン。「コード実行とファイル作成」を ON | PowerPoint・PDF・Google スライド (Google スライドは編集できる形) | **作ったスライドは claude.ai (Anthropic のサーバー) に保存され、サイドバーの Artifacts に残ります。** 使うかどうかはご自身で判断してください。PowerPoint に書き出した時に文字が編集できるか・日本語の書体が崩れないかは、まだ確かめていません |
| ChatGPT のスライド機能 (ChatGPT Slides) | Pro・Business・Enterprise のうち、対象の人から順に提供 (2026-10-16 から) (要約で確認) | PowerPoint・PDF・Google スライド (要約で確認) | 未検証 |
| ChatGPT for PowerPoint (PowerPoint の追加機能) | 無料を含む全プラン。無料と Go は利用量に制限 (要約で確認) | PowerPoint の中で直接作る | 未検証 |
| Claude for PowerPoint (PowerPoint の追加機能) | Pro・Max・Team・Enterprise (無料は対象外) | PowerPoint の中で直接作る | Web 版 PowerPoint、Microsoft 365 の Windows 版、Mac 版 16.46 以降。未検証 |
| Gemini の Canvas でスライドを作る | Google AI Pro・Ultra、多くの Google Workspace のプラン (要約で確認)。無料で使えるかは公式ページに記載なし | Google スライド・PDF | 未検証 |

### Claude Slides と組み合わせる (Claude のスキルかプロジェクトで使っている時)

1. 出典一覧と確認リストまで出し終えたら、同じチャットで「この文面で Claude Slides のスライドを作って。文言・数字・[要確認] は変えないで。読み原稿はノートに入れて」と頼む。
2. AI が「claude.ai に保存されます。作ってよいですか」と聞くので、よければ「はい」。
3. できたスライドを、承認したスライド文面と見比べる。AI も違いを一覧で伝えます (これも検品ではありません)。
4. スライドの画面で直したい所を指して直せます。直した後も、数字と [要確認] が残っているかを確かめてください。

ChatGPT や Gemini で作った時は、スライド文面を上の表の道具に貼り、同じ一文 (「文言・数字・[要確認] は変えないで」) を添えて頼んでください。

## 7. 守っていること (指示文の中の約束)

- 要約に「はい」をもらうまで作らない。
- 「確認済み」と書くのは、会話の中で公的なページを実際に開き、本文をそのまま引用できたものだけ。あなたが本文を貼ってくれた時も、それを引用にします。
- 確かめられない所は [要確認]。数字・日付・金額を作らない。
- 「検品済み」と言わない。最後に「未検品」と表示し、確認リストを渡す。
- 顧問先の個人の情報は、資料にもメモカードにも書かない。検索の言葉にも入れない。

## 8. ファイルの関係 (直す人向け)

- 正本は `instructions.md` と `knowledge/` の 3 つ。`claude-ai-skill/shiryo-kit-chat/` の `SKILL.md` と `references/` は、そこから作った写しです。直接直さず、正本を直してから次を実行します。
  ```
  python3 chat/tools/build_claude_skill.py           # 写しを作り直す
  python3 chat/tools/build_claude_skill.py --check   # 写しが正本とずれていれば終了コード 1
  ```
- スキルの説明文 (description) は 200 字まで、frontmatter は `name` と `description` だけ (claude.ai のアップロードがそれ以外を受け付けないため)。名前に "claude" "anthropic" を入れない。
- 指示文は 8,000 字以内に保つ。ChatGPT・Claude のプロジェクトと Gemini の Gem の指示欄の上限は公式ページに書かれていない。8,000 字は第三者の記載とカスタム GPT のエラー文から取った安全側の目安。
- 根拠にした公式ページ (2026-10-18 に確認): ChatGPT のプロジェクト https://help.openai.com/en/articles/10169521-projects-in-chatgpt (本文は開けず要約で確認) / Claude のプロジェクト https://support.claude.com/en/articles/9517075-what-are-projects / Claude のスキル https://support.claude.com/en/articles/12512180-use-skills-in-claude と https://support.claude.com/en/articles/12512198-how-to-create-custom-skills / Claude Slides https://support.claude.com/en/articles/17153992-what-are-artifacts-and-how-do-i-use-them / Claude for PowerPoint https://claude.com/docs/office-agents/powerpoint / Gemini の Gem https://support.google.com/gemini/answer/15146780 / Gemini のスキル https://support.google.com/gemini/answer/17094296 / Gemini の Canvas の書き出し https://support.google.com/gemini/answer/16047321 / ChatGPT Slides https://help.openai.com/en/articles/20001605-creating-and-collaborating-on-slides-in-chatgpt と ChatGPT for PowerPoint https://help.openai.com/en/articles/20001242-chatgpt-for-powerpoint (どちらも要約で確認)。
- 中身は、エージェント版 `skill/shiryo-kit/` の SKILL.md と references (hearing・evidence・doctrine・memory・voice・review) を、チャットアプリ向けに短くしたもの。出典は各参考資料の末尾にあります。
