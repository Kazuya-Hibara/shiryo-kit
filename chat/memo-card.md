# メモカード — 次回の資料づくりを「続きから」始めるためのカード

チャット版は、会話が終わると前回の答えを覚えていません (アプリの記憶機能には頼りません)。
そこで、資料ができた最後に AI が「メモカード」を出します。次に資料を作る時、新しい会話の最初にこのカードを貼ると、前回の答えを「おすすめの答え」として出してくれるので、同じことを一から聞かれずに済みます。

## カードの形

```
=== shiryo-kit メモカード (作成日: YYYY-MM-DD) ===
次回は、新しい会話の最初にこのカードをそのまま貼ってください。

【事務所共通】どの資料でも使う
- 話し手・事務所の紹介 (資料に載せてよい範囲):
- 口調: 語尾 / よく使う言い回し「」 / 構成の癖 / 使わない言い方
- 型の好み:
- よく使う出典 (次回も必ず開き直して確かめる): 資料名 / URL / 確認日

【案件限定: 呼び名】この相手・この回の続きの時だけ使う
- 受け手:
- 場面:
- 言わないこと:
- 説明済みの話題:
- 残った [要確認]:
- 【仮置き】本人が確かめていない推測 (次回は聞き直す):

【使わない】訂正・削除したこと (要点だけ)
-

顧問先の個人情報 (氏名・連絡先・健康情報など) は入れていません。
=== ここまで ===
```

## 区分

| 区分 | 入るもの | 次回の使われ方 |
|---|---|---|
| 【事務所共通】 | 話し手・事務所の紹介、口調、型の好み、よく使う出典。どの案件にも当てはまることだけ (特定の案件の受け手・場面・人数・日付は入れない) | どの資料でも「おすすめの答え」になる。最初に「変わっていませんか」と 1 回だけ確かめられる |
| 【案件限定: 呼び名】 | その顧問先・その回だけの事情 (受け手、場面、言わないこと、説明済みの話題、残った [要確認]) | 同じ相手・同じ回の続きの時だけ使う。別の顧問先・別の回の資料には持ち込まない。新しいカードにも、続きの時か、あなたが「残して」と言った時だけ写されます |
| 【仮置き】(案件限定の中) | AI が推測で置いた数字など、あなたが確かめていない値 (例「時間 40 分 (推測)」) | 事実としては使わず、次回もう一度聞かれる |
| 【使わない】 | 訂正・削除したことの要点 (例「旧事務所名を使わない」) | 次回以降、その内容を使わない。あなたが「外して」と言わない限り、新しいカードにも全部写されます |

迷うものは【案件限定】に入れます (別の相手に持ち越してしまう事故の方が困るため)。
新しい案件の欄には、その会話であなたが言ったことと添付から読んだことだけが入ります (前の案件の欄の言葉は借りません)。今回だけの指定 (「今回はクイズなし」など) では【事務所共通】は変わりません。変えたい時は「今後も」と言ってください。

## 入れないもの

顧問先の従業員や相談者の氏名・連絡先・住所・生年月日・健康や障害のこと・マイナンバー・個人ごとの給与・相談の中身そのもの。過去資料の長い写し。
顧問先は「A 社」「B 社」「商工会 秋のセミナー」のような呼び名で書きます。別の相手には別の呼び名を付けます (同じ「A 社」を 2 つの顧問先に使わない)。カードに個人の情報が入っていたら、貼る前に消してください。

## 次回の使い方

1. 新しい会話 (同じプロジェクトや Gem の中) を開く。
2. 最初のメッセージに、カードを `=== shiryo-kit メモカード` から `=== ここまで ===` までそのまま貼り、続けて今回の依頼を書く。
   ```
   (メモカードを貼る)

   今回は、A 社の社長向けに、就業規則の改定の説明資料をお願いします。
   ```
3. AI は【事務所共通】をおすすめの答えにして、変わっていないかを確かめます。【案件限定】は、今回が同じ相手の続きかを確かめてから使います。
4. 「よく使う出典」は、前回確かめた物でも、もう一度開いて確かめ直します (制度や年度が変わっていることがあるため)。

## 直したい・消したい時

| こう言う | AI がすること |
|---|---|
| 「口調の『〜』は違います。正しくは『…』」 | 新しいカードで直す |
| 「旧事務所名はもう使わないで」 | 新しいカードから消し、【使わない】に要点を書く |
| 「今回だけ 30 分にして」 | 今回の資料だけ変える。カードの値は変えない |
| 「A 社の分は全部消して」 | 新しいカードから【案件限定: A 社】を消す |

カードは資料ごとに新しいものが出ます。同じ相手の続きなら、いちばん新しいカードを残し、古いものは捨ててかまいません。
別の顧問先・別の回の資料を作ると、新しいカードには前の案件の欄が入りません (AI が「前回のカードの案件の欄は入れていません」と伝えます)。前のカードは捨てずに残してください。事務所共通の部分だけを残したカードを 1 枚、顧問先ごとのカードを別に持っておくと、貼り間違いを防げます。

## 置き場所の例

カードは文字だけなので、どこに保存してもかまいません: パソコンのメモ帳 (テキストファイル)、Word、事務所の共有フォルダなど。
チャットアプリのプロジェクトのファイル欄に置く使い方もできますが、その場合は顧問先ごとのカードを混ぜないでください (全部の会話から見えるため)。

## エージェント版との関係

エージェント版 (Claude Code・Codex) は、同じ区分のメモを利用者のフォルダの `資料メモ/` に保存します (`事務所共通.md`・回ごとの `案件/<年月>_<呼び名>-<回>.md`・`訂正ログ.md`)。チャット版のカードは、その内容を 1 枚の文字にまとめたものです。
