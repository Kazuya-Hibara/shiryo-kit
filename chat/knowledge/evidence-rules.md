# 出典の確かめ方 (shiryo-kit チャット版・参考資料)

指示文の「4. 出典を確かめる」「7. 出典一覧」を補う資料。指示文と食い違ったら指示文を優先する。

## いちばん大事な決まり

士業の資料で一番怖いのは、もっともらしい間違い (古い制度・未施行の改正・対象違い・作られた数字)。

- 「確認済み」と書けるのは、この会話の中で次の全部を満たしたものだけ:
  1. 検索・閲覧の機能で、公的な原典のページ (または PDF) を実際に開いた。(本人が原典の本文を貼ってくれた時は、区分を「本人が貼付」にする。下の §2)
  2. 主張を支える箇所を、本文からそのまま引用できる。
  3. 主張と原典が、数字・単位・条件・対象・強さまで一致する。
  4. 基準日の時点で有効だと確かめた (下の「適用時点」)。
- 確認の根拠にしないもの: モデルの記憶、検索結果の見出しや要約文、解説記事、他の事務所のサイト、まとめサイト、過去の資料、本人の記憶や下調べメモ。これらは原典を探す手がかりには使ってよい。
- 開けない・リンク切れ・内容が違う・基準日に有効でない → 「未確認」。理由を書く。
- 自分が本当にページを開いたか、引用が本文そのままか自信が無い時は「未確認」。
- 未確認の主張は、資料のその場所に [要確認] を出す。数字・日付・金額は推測で埋めない。
- 検索語に顧問先の名前・従業員の情報を入れない。検索した言葉と開いた URL は最後に一覧で見せる。

## 1. 主張を抜き出す

骨子の段階で一度、文面と原稿を書いた後にもう一度、全部から抜き出す (書くと主張が増えるため)。

見る場所: タイトル・本文・図のラベルと数値・表の各セル・注記・読み原稿・表紙の日付。

確認が要る主張:
- 法令の条文・制度の説明 (「〜が義務になった」「罰則がある」「努力義務」)
- 金額・率・上限・下限 (保険料率、最低賃金、助成額、割増率)
- 日付・期限・期間 (施行日、申請期限、「来年 4 月から」)
- 対象・要件 (企業規模、人数とその数え方、業種、年齢、区分)
- 手続き・様式・提出先
- 統計・調査の数字
- 比べる言い方 (「〜より有利」「全国平均より高い」)

隠れた主張: 「すべての会社が対象」(対象)、「今年から」(日付)、「必ずもらえる」(要件と受給)。「来年」「今年の 10 月」のような相対的な日付は、基準日をもとに年月日に直してから確かめる。

確認が要らないもの: 話し手の意見・経験談 (意見として書く限り)、事務所自身のサービス内容と料金 (本人提供)、架空と分かる例 (「例」と書く)。

## 2. 区分

| 区分 | 意味 | 資料での見せ方 |
|---|---|---|
| 確認済み | 上の 4 条件を全部満たした | 出典を表示 (資料名と確認日) |
| 未確認 | 確かめられなかった。理由: 検索機能なし / 原典なし / 開けない / リンク切れ / 原典と食い違い / 旧制度 / 未施行 / 対象違い / 年度・地域違い / 改正案で未決 | その場所に [要確認] |
| 本人が貼付 | 本人が原典の本文を貼ってくれ、それを引用にした (作り手はページを開いていない) | 出典を表示し「本人が貼付」と書く。適用時点は「貼付時点の記載 (確認日)」。貼られたページがいつ更新されたかは分からないので、基準日に有効かは [要確認] として本人に確かめてもらう |
| 本人提供 | 本人が言った・本人の資料にあった (原典で照らしていない) | 原典で確かめられればそうする。できなければ一覧で「本人提供 (原典未照合)」 |

本人提供の数字が原典と食い違ったら、黙って直さない。根拠を見せて本人に聞く (新しい事実による質問)。

## 3. 原典の優先順と所在

優先順: ① 法令の本文 → ② 所管の官庁の説明・通知 → ③ 実施する機関の案内 → ④ 公募要領・支給要領 (最新の年度版)。

| 種類 | 原典 |
|---|---|
| 法律・政令・省令の本文、附則 (施行期日・経過措置) | e-Gov 法令検索 https://laws.e-gov.go.jp/ |
| 公布されたか・公布日 | 官報 https://www.kanpo.go.jp/ |
| 労働・社会保険の制度説明、法改正のお知らせ | 厚生労働省 https://www.mhlw.go.jp/ |
| 雇用関係の助成金 (支給要領・申請期間・受付停止) | 厚生労働省の助成金のページ、各都道府県労働局 |
| 地域の運用・最低賃金 | 各都道府県労働局 https://jsite.mhlw.go.jp/ |
| 年金・厚生年金保険の手続きと保険料 | 日本年金機構 https://www.nenkin.go.jp/ |
| 協会けんぽの保険料率 (都道府県別・年度別) | 全国健康保険協会 https://www.kyoukaikenpo.or.jp/ |
| 中小企業の施策・補助金 | 中小企業庁 https://www.chusho.meti.go.jp/、各補助金の公募要領 |
| 税 | 国税庁 https://www.nta.go.jp/ |
| 自治体の制度 | 各自治体の公式サイト |

所在は 2026-10 時点。開く時に URL が変わっていないか確かめる。

チャットアプリでの注意:
- 検索・閲覧の機能が使える設定か、会話の最初に分からなければ、使ってみて結果のページ本文が読めるかで確かめる。読めなければ「この会話では原典を開けないので、確認が要る所は全部 [要確認] にします」と伝える。
- PDF の要領・リーフレットは本文を読む。読めなければ未確認 (開けない)。
- 自動の閲覧を断るサイトがある。開けなければ未確認とし、本人に開いて確かめてもらう場所 (サイト名・ページ名) を伝える。本人が本文を貼ってくれたら、それを引用にしてよい (「本人が貼付」)。
- 同じ名前の資料に年度版がある時は、基準日に有効な版を選び、版 (「令和 8 年度版」など) を書く。

## 4. 照らし合わせる

- 数字は単位と条件まで一致させる (月額/日額、以上/超、税込/税抜、人数の数え方)。
- 主張が原典より強くないか (「できる」を「必ず」、「努力義務」を「義務」にしていないか)。
- 原典の条件を落としていないか (「中小企業のみ」「一定の要件を満たす場合」)。

## 5. 適用時点を確かめる (毎回)

| 罠 | 確かめ方 | 扱い |
|---|---|---|
| 旧制度 | 改正の履歴を見て、基準日に有効な版と照らす | 古い内容なら未確認 (旧制度) |
| 公布済み・未施行 | 附則の施行期日と基準日を比べる | 今の制度として書かない。「◯年◯月◯日施行予定」と施行日の原典つきで書き分ける |
| 経過措置 | 附則の経過措置を読む | 対象によって旧ルールが続くなら、その条件を書くか未確認に |
| 対象違い | 規模・人数 (数え方も)・業種・年齢・区分の条件を読む | 受け手の会社に当てはまらない内容を一般論として書かない |
| 年度・地域違い | 料率・最低賃金・助成額の年度と都道府県 | 基準日の年度・受け手の地域の値でなければ未確認 |
| 受付状況 | 助成金・補助金の公募期間・受付停止 | 受付が終わっている・改定予告があれば書く |
| 改正案 | パブリックコメント・審議中の法案 | 決まったこととして書かない |

使う日が基準日より後なら、使う日にも有効かを一言確かめる。

本人が貼った本文は、貼られた時点の記載として扱う。「基準日に有効」とは書かず、基準日に有効かは [要確認] (ページの更新日・改正の有無を本人に確かめてもらう) とする。

## 6. メモカードの「よく使う出典」

前回の出典は手がかり。新しい資料で使う時は必ず開き直し、内容・版・年度が変わっていないかを確かめてから確認済みにする。

## 出典

- 根拠の台帳を先に作り、欠け・食い違いを記録する: CyberPPT (MIT)
- 一次情報だけを主張の根拠にする: mattpocock/skills `research` (MIT)
- 作り手の申告は証拠ではない、主張を抜き出して反証を試みる: BMAD-METHOD `claims-check` (MIT)
- 数字は根拠資料と全部突き合わせ、出典は固有名と日付で書く: 提供者の社内スライド検品基準を一般化
- 原典の所在: 各機関の公式サイト (2026-10 時点)
- エージェント版の `skill/shiryo-kit/references/evidence.md` をチャットアプリ向けに短くしたもの
