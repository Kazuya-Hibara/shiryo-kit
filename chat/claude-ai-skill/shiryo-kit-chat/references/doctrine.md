# 資料の判断の軸 (shiryo-kit チャット版・参考資料)

指示文の「3. 骨子」「5. スライド文面」「6. 読み原稿」を補う資料。数値の目安は既定値で、絶対の決まりではない。

## 1. 決める順番

1. 場面 (話すのか配るのか) を先に決める。文字の量・枚数・付録の扱いはこれで決まる。
2. 構造 (言いたいことと順番) を見た目より先に決める。
3. 中身 (根拠・図表・原稿) → 見た目 の順。

## 2. 場面

| 場面 | 判断 |
|---|---|
| 投影して話す (セミナー・講演) | 1 枚の文字は少なく、説明は読み原稿へ |
| 配る・回覧される (顧問先への説明、提案書) | それだけで論拠が分かる密度にする。文字が多いこと自体は欠点ではない |
| 両方 (投影 + 同じ PDF を配布) | どちらかに寄せると決める: 投影は少なめ + 原稿つき PDF、または読める密度の 1 本 |

- 中途半端な密度が一番読みにくい。文字が多すぎる 1 枚は、削って原稿へ移すか、文書として作ると決める。
- 「画面と声で同じ文字を出さない」は話す場面の話。配る資料に当てはめない。
- 日本の顧問先では同席しない人に回覧されることが多い。迷ったら「配る」側に倒す。

## 3. タイトル

- タイトルは結論を 1 文で言う。「何についてか」でなく「だから何か」。名詞だけ (「現状」「制度の概要」) にしない。
  - 悪い:「残業申請の現状」 → 良い:「残業申請が紙のままなので、月末の集計に毎月 2 日かかっている」(架空の例)
- タイトルだけを順に読んで話が通るか確かめる。失敗は 3 つ: 話題の羅列、重複、つながりが無い。
- 本文・図表は「なぜこのタイトルを信じてよいか」に答える。答えない要素は削るか付録へ。
- 1 枚 1 メッセージ。タイトルに主張が 2 つ並んだら 2 枚に分ける。
- 結論を伏せる煽り (「成果が変わる唯一の方法」) や、構成を語るだけ (「本日お伝えすること」) はタイトルにしない。
- 表紙・目次・章扉・付録は対象外。表紙は事務的に (題・宛先・事務所名・日付)。
- 長さは全角 40 字前後・2 行以内が目安。

## 4. 骨子と流れ

- 骨子はタイトル列 (+ 各枚の根拠のメモ) だけで先に書く。矛盾は一覧の方が見つかる。
- 結論は最初の数枚に出す。
- まとめの 1 枚は中身が固まってから最後に書く。
- 流れは受け手がどこまで納得しているかで選ぶ:

| 受け手の状態 | 例 | 流れ |
|---|---|---|
| 頼まれて説明・報告する | 顧問先への説明、報告 | 結論 → 理由 → 何をいつまでに |
| 問題意識がまだ無い | セミナーの聴衆 | 何が変わったか (基準日つき) → 自分に関係あるか → 何をすればよいか |
| 必要性に合意していない | 新しい相手への提案 | 相手の困りごと (相手の言葉で) → 解決の要点 → 中身 → 進め方と費用 → 決めてほしいこと |

- 反発を呼びそうな結論は、状況 → 困りごと → 問い → 答え の順で。
- 抽象的な枚が 4 枚続いたら、具体 (画面・数字・事例) を挟む。
- 枚数に上限は決めない。タイトル列で話が通るかで判断し、溢れた材料は付録へ。

## 5. 型 (4 つ)

エージェント版の型見本 (`skill/shiryo-kit/assets/kata/`) の並びを言葉にしたもの。表紙の後の並び:

| 型 | 骨格の例 |
|---|---|
| セミナー | 今日の話の順番 → 何が変わったか → 自分の会社が対象か → 進め方 → 抜けやすい所 → 課題の分け方 → 自社で確かめる表 → 持ち帰ること |
| 顧問先説明 | 結論 (何をいつまでに) → 何が変わったか → 制度の中身 (内容・対象・注意点) → いまの規程との差 → 事例 (架空) → 対応しないと起きること → 進め方と期間 → お願いしたいこと → 決めてほしいこと |
| 提案 | 相手の困りごと → 打つ手 → 提案の柱 → 範囲・頻度・成果物 → 契約の形 → 進め方 → 費用 → 事例 (架空) → 決めてほしいこと |
| 報告 | 結論 → 調べ方 → 分かった事実 → 要対応の件 → 状況の一覧 → 所見と次にやること → 次回までにすること |

型に無い依頼 (社内研修の配布資料など) は、近い型を土台に組み替える案を言葉で示して了承をもらう。

## 6. 日本語の言葉づかい

- タイトルの「です・ます」と言い切りは資料の中でそろえる。
- 箇条書きは、丁寧体の資料でも言い切り・体言止めでよい。
- 体言止めは数字や帰結を含む時だけ (「手続き 3 つで申請完了」)。飾りの体言止め (「未来へ、共に。」) は使わない。
- 疑問形のタイトルは要所 1 か所程度にし、次の枚ですぐ答える。
- 相手の発言は言い換えず「」でそのまま。
- 句読点・和暦/西暦・敬称は本人の過去資料に合わせる。

## 7. 数字と出典

- 資料の数字は、すべて出典一覧にある数字だけ。
- 細かさは確かさではない。丸め方を資料の中でそろえる。
- 出典は固有名と日付・年度で書く。「各種資料より」「厚労省資料より」だけにしない。
- 助成金・補助金は受給を約束しない。要件と受付状況を添え、確認日を書く。

## 8. 図と表

- 先に言いたいこと → 比べ方 (割合・順位・推移・分布・関係) → 図の形式、の順で選ぶ。
- 図のタイトルもメッセージにする。3D・二重の縦軸は使わない。円グラフは 4〜5 区分まで。
- 飾りの画像は、外しても意味が減らないなら外す。
- 表は本物の表として作る (後で直せるように)。チャット版では行と列を文字で書く。

## 9. 読み原稿

- スライドの読み上げではなく、話す言葉で書く (本人の口調で)。
- 1 枚ごとに「必ず言うこと」を 2〜5 個。時間の配分を持ち時間に合わせる。
- 原稿にだけ出る数字・制度の説明にも出典の決まりが効く。

## 10. やりすぎに注意

- 配る資料に「文字を減らせ」を当てはめない。表紙・章扉にまで結論型タイトルを求めない。
- 「3 つが最適」「最大 7 つ」を絶対の決まりにしない。
