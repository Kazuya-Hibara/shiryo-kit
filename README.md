# shiryo-kit — 聴き切ってから作る、出典を確かめた資料づくり

セミナー資料・顧問先への説明資料・提案資料・報告資料を、AI と一緒に作るための道具です。一人で事務所を回している社労士などの士業の方や、中小企業の担当の方に向けて作りました。
作り始める前に AI が必要なことを聴き取り、法令や金額は公的な原典 (役所や e-Gov 法令検索などの元の資料) で確かめ、確かめられない所は **[要確認]** と書いて残します。

> ### 初めての方は「チャット版」から
>
> ふだんお使いの **ChatGPT・Claude・Gemini に、指示文を 1 つ貼るだけ** で使えます。ソフトを入れる必要も、ターミナル (黒い画面) も要りません。
>
> 1. このページの上の方にある緑色の **「Code」** ボタンを押し、**「Download ZIP」** を選びます。ダウンロードした ZIP を開きます (Mac はダブルクリック、Windows は右クリック →「すべて展開」)。ZIP をメールなどで受け取った方は、展開から始めてください。
> 2. 開いたフォルダの中の **`chat` フォルダ** にある **`instructions.md`** を開き、全部コピーします。ダブルクリックで開けない時は、右クリック →「プログラムから開く」→「メモ帳」(Windows) / 右クリック →「このアプリケーションで開く」→「テキストエディット」(Mac)。文字を全部選んでコピーできれば、どのアプリでもかまいません。
> 3. お使いの AI で「プロジェクト」を作り、指示の欄に貼って保存します。
>    - ChatGPT: 左の欄の「プロジェクト」→ 新しいプロジェクト → 右上の「…」→「プロジェクト設定」→ 指示の欄に貼る
>    - Claude: 「プロジェクト」→ 新しいプロジェクト →「プロジェクトの指示を設定」に貼る
>    - Gemini: 左の欄の「Gem」→ 新しい Gem →「指示」の欄に貼る (パソコンのブラウザで)
> 4. そのプロジェクトの中で新しいチャットを始め、「セミナー資料を作りたい」と頼みます。AI が目的・聞く人・時間・何日時点の制度で書くかなどを、おすすめの答えつきでまとめて聞いてきます。過去の資料があれば、その時に添付できます。
>
> **顧問先の従業員の名前・連絡先・健康のことなどは、貼らないでください。** 貼った内容は AI の会社のサーバーに送られます。
>
> もっと詳しい手順 (画面の説明・うまくいかない時) は **[チャット版の始め方 (chat/README.md)](chat/README.md)** にあります。このページの残りは、読まなくても使えます。

> **まだ「未検証」です。** これまでの動作の確認は、作った側の Mac で、架空のデータを使って行っただけです。実際の利用者の環境 (Windows を含む) で、最初から最後まで通す試験はまだしていません。終わった環境から「未検証」を外します。

## 2 つの版

| | チャット版 | エージェント版 |
|---|---|---|
| 向いている方 | **初めての方。** ソフトを入れたくない方。まず試したい方 | **Claude Code か Codex を既に使っている方** (またはご自分で入れられる方) |
| 使うもの | ふだんの ChatGPT・Claude・Gemini (ブラウザかアプリ) | Claude Code か Codex (パソコンの中のファイルを読み書きする AI) |
| 要るプラン | ChatGPT と Claude は、無料プランでもプロジェクトを作れます (2026-10-18 時点。下の「対応環境」)。無料プランは使える量が少なく、長い資料は途中で止まりやすいので、続けて使うなら有料プラン (ChatGPT なら Plus、Claude なら Pro など) が向いています。迷ったら、まず今のプランで試し、途中で止まることが多ければ有料に変えてください | **有料プランが要ります。** Claude Code は Claude の有料プラン (Pro・Max・Team・Enterprise)。Codex は ChatGPT の有料プラン (Plus・Pro・Business など) |
| できあがる物 | 骨子・スライド文面・読み原稿・出典一覧・確認リストの文章 (見た目のスライドは各社のスライド機能で作る) | 編集できる PowerPoint・PDF・読み原稿・出典一覧・点検の記録 |
| 始め方 | [chat/README.md](chat/README.md) | [docs/agent-setup.md](docs/agent-setup.md) |

金額は各社がよく変えるので、ここには書きません。各社のサイトの料金のページでご確認ください。

チャット版は、エージェント版より品質が少し落ちます。いちばん大きな違いは次の 2 つです。

- **編集できる PowerPoint のファイルを、チャット版は自分では作りません。** 見た目のスライドは、各社のスライド機能に文面を渡して作ります (文字が直せる形になるかは、まだ確かめていません)。
- **チャット版は「別の AI による点検」ができません。** 同じ会話の中で見直すだけなので、最後は必ず「未検品」と表示します。

ほかに、過去資料は手で添付する、AI が本当に原典のページを開いたかをプログラムで確かめられない、聞いた内容は「メモカード」を次回に貼り直す、という違いがあります。詳しくは [chat/README.md](chat/README.md) の §2 にあります。

## エージェント版 (Claude Code・Codex を既に使っている方向け)

Claude Code か Codex をふだん使っている方は、こちらの方が品質が上がります。準備の流れは次の通りです。細かい手順と、うまくいかない時の対処は **[docs/agent-setup.md](docs/agent-setup.md)** にまとめてあります。

1. 上と同じ「Code」→「Download ZIP」でフォルダを取り、展開します。
2. そのフォルダで Claude Code か Codex を開き、「このフォルダの install.sh を --claude を付けて実行して」(Codex なら --codex) と頼みます。Windows は install.ps1 です (まだ一度も動かしていません)。
3. AI の種類 (モデル) は、画面のモデル選択で、Claude Code なら名前に **「Opus」** と付くもの、Codex なら **「gpt-6-astra」** を選び、考える深さ (effort) は **「high」** にします。分からなければ、AI に「モデルを Opus 5.5 の high にする方法を教えて」と聞けば教えてくれます。
4. 資料を置きたいフォルダで「セミナー資料を作りたい」と頼みます。

正直に書くと、Codex (gpt-6-astra) は Claude Code (Opus 5.5) より品質が少し落ちます (作った側の評価です)。全部の工程は Codex でも動くように作ってあります。

## 何が違うのか

エージェント版は、設計としてこう作ってあります (実際の利用者の環境ではまだ確かめていません)。チャット版で弱くなる所は、上の「2 つの版」の下に書いた通りです。

- **作る前に、一度にまとめて聞きます。** 目的・聞く人・時間・何日時点の制度で書くか・入れない話題・口調・欲しい物など。おすすめの答えが付いているので「はい」か番号で答えられます。最後に要約を見せ、あなたが「この内容で」と言うまで作りません。
- **原典の本文をそのまま引用できたものだけを「確認済み」と呼びます。** 原典のページを実際に取得して保存し、引用した文が本当にそこにあるかをプログラムで確かめます。取れなかった・合わなかった・まだ施行されていない・対象が違う所は、資料の中に **[要確認]** と出し、数字を作りません。
- **あなたの過去の資料から、口調と構成の癖を抜き出します。** どのファイルのどの言い回しかを見せて確かめてから、文面と読み原稿に反映します。
- **作った AI とは別の AI が点検します。** 要件どおりか・原典と合っているか・言い過ぎていないかを見ます。点検できなかった時は「未検品」と表示し、完了とは言いません。点検した版と、お渡しする版が同じかも確かめます。
- **聞いたことをメモに残し、次回はおすすめの答えとして出します。** 残す前に必ず見せます。別の顧問先の話は持ち込みません。

それでも AI は間違えることがあります。人前に出す前に、[要確認] の所と、出典一覧の URL は必ずご自分で開いて確かめてください。この道具は法律の助言をするものではありません。

## 対応環境

**全部「未検証」です** (実際の利用者の環境で、入口から成果物まで通す試験をまだしていません)。プランの条件は 2026-10-18 時点で各社の公式ページを調べた内容で、変わることがあります。細かい表と根拠は、チャット版は [chat/README.md](chat/README.md) の §3、エージェント版は [docs/agent-setup.md](docs/agent-setup.md) の「対応環境」と [docs/compat.md](docs/compat.md) にあります。

| 環境 | 必要なプラン | 初期設定 | 使えない・弱い機能 | 検証状況 |
|---|---|---|---|---|
| ChatGPT の「プロジェクト」(チャット版) | 無料を含む全プラン | 指示の欄に `chat/instructions.md` を貼る | 別の AI による点検、編集できる PowerPoint の書き出し、原典を開いたかの機械の確認 | 未検証 |
| Claude の「プロジェクト」(チャット版) | 無料を含む全プラン (無料はプロジェクト 5 つまで) | 同上 | 同上 | 未検証 |
| Gemini の「Gem」(チャット版) | 公式ページに記載なし | 同上 (パソコンのブラウザで作る) | 同上。個人のアカウントでは 2026-11-17 から「スキル」に移る | 未検証 |
| Claude Code (エージェント版) | Claude の Pro・Max・Team・Enterprise か API の契約。無料プランでは使えない | `install.sh --claude` / `install.ps1 -Claude` | 画面で指して直す: 未確認。Windows の install.ps1 は一度も動かしていない | 未検証 |
| Codex (エージェント版) | ChatGPT の Plus 以上 (無料・Go でおすすめのモデルが使えるかは未確認) | `install.sh --codex` / `install.ps1 -Codex` | 画面で指して直す: 未確認。原典を取りに行く時、ネットへの接続の許可を求められることがある | 未検証 |

ChatGPT の行の条件は、公式ページが開けず、検索結果の要約で確かめたものです。PowerPoint で開いた時の崩れは、まだ実際の PowerPoint (Windows・Mac) で確かめていません。

## 顧問先の情報と、AI の会社に送られるもの

- どちらの版も、会話と、AI に読ませたファイルの中身は、AI の会社 (ChatGPT は OpenAI、Claude は Anthropic、Gemini は Google) のサーバーに送られて処理されます。
- **顧問先の従業員の名前・連絡先・健康のこと・給与などは、貼らない・読ませないでください。** AI は写さない決まりにしてありますが、送らないのがいちばん確かです。過去資料は、先に個人の情報を消すか伏せてから使ってください。
- 会話が AI の学習に使われる設定になっていないか、使う前に各社の設定画面で確かめてください。画面の名前の例 (2026-10 時点。変わることがあります): ChatGPT は「設定」→「データコントロール」、Claude は「設定」→「プライバシー」、Gemini は「アクティビティ」(「アクティビティを保持」)。会社のプラン (Team・Business・Enterprise など) は、契約で扱いが決まっていることが多いので、管理者に確かめてください。
- 守秘義務との関係は、最後はご自身の判断になります。何を読み・何を外に送り・何を保存するかの一覧は、エージェント版は [docs/agent-setup.md](docs/agent-setup.md) の「何を読み、何を外に送り、何を保存するか」、チャット版は [chat/README.md](chat/README.md) の §2 にあります。

## できないこと・限界

- **AI は間違えます。** 「確認済み」は「原典のページに同じ文がある」ことまでで、その読み方が正しいか、あなたの顧問先に当てはまるかまでは保証しません。人前に出す前に、ご自身で確かめてください。法律の助言はしません。
- 原典を取りに行けない環境 (ネットにつながらない、取得が止められている) では、主張は全部 [要確認] になります。
- 図や絵の中の文字は、PowerPoint で直せない絵になります (読ませる文字は図の外の文字として置きます)。
- 見た目は、既にある部品を流用した落ち着いたデザインです。凝ったデザインや、事務所のひな形に合わせることはしません。
- 過去資料が少ない・無い時は、口調の反映が浅くなります (その時は聴き取りで口調を聞きます)。
- 1 つの資料を作るのに、聴き取り・原典の確認・点検で時間がかかります。速さより、間違えないことを優先しています。

## ことば

| ことば | 意味 |
|---|---|
| エージェント | パソコンの中のファイルを読んだり、プログラムを動かしたりしながら作業する AI。Claude Code と Codex がそれ |
| スキル | AI に追加で渡す手順書のフォルダ。shiryo-kit はスキルとして入れます |
| 文字で操作する版 | 黒い画面 (ターミナル) に文字を打って使う版。デスクトップアプリでも同じことができます |
| 原典 | 法令・通達・役所の案内など、元の公的な資料。解説記事や他の事務所のサイトは原典に入れません |
| 検品・点検 | 作った AI とは別の AI が、出来た資料を確かめること。できなかった時は「未検品」と表示します |
| 出典台帳 | 資料の中の「確かめが要る主張」の一覧。どこで確かめたか・確かめられなかったかを 1 行ずつ書きます |
| モデル / effort | AI の種類と、考える深さ。エージェント版では「Opus」(Claude Code) か「gpt-6-astra」(Codex) を、考える深さ「high」で使います |
| プロジェクト | ChatGPT・Claude の機能。指示文を 1 回貼っておくと、その中の会話すべてで使われます。チャット版はこれを使います |
| Gem | Gemini の機能。プロジェクトと同じように、指示文を貼っておけます |
